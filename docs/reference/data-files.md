# Data files

Generated app data lives under:

```text
public/data/
```

Do not treat generated JSON as the source of truth. Source content lives under `content/`.

## Generation map

```mermaid
flowchart LR
    src["content/**"]
    validate["npm run content:validate"]
    build["npm run content:build"]
    concepts["public/data/concepts.json"]
    quiz["public/data/quiz/*.json"]
    index["public/data/search-index.json"]
    sections["public/data/concept-sections/*.json"]

    src --> validate
    validate --> build
    build --> concepts
    build --> quiz
    build --> index
    build --> sections

    concepts --> nav["Index, navigation, quiz launcher"]
    quiz --> session["Quiz session"]
    index --> search["MiniSearch"]
    sections --> assistant["Assistant grounding"]
```

## `concepts.json`

Path:

```text
public/data/concepts.json
```

Generated by:

```bash
npm run content:build
```

Contains concept metadata derived from MDX frontmatter plus app fields:

- `slug`
- `href`
- `quizCount`
- `hasQuiz`

## Quiz JSON

Path pattern:

```text
public/data/quiz/<safe-concept-id>.json
```

Concept IDs are made safe by replacing `/` with `__`.

```mermaid
flowchart LR
    id["general-ml/bias-variance"] --> safe["general-ml__bias-variance"]
    safe --> quizpath["public/data/quiz/general-ml__bias-variance.json"]
    safe --> secpath["public/data/concept-sections/general-ml__bias-variance.json"]
```

## Search index

Path:

```text
public/data/search-index.json
```

Generated from MDX content sections.

Used by:

```text
src/lib/retrieval/search.ts
```

## Concept sections

Path pattern:

```text
public/data/concept-sections/<safe-concept-id>.json
```

Used for assistant grounding and section ranking.

## Build scripts

Relevant scripts:

```text
scripts/validate-content.mjs
scripts/build-content.mjs
scripts/build-search-index.mjs
```

Package commands:

```bash
npm run content:validate
npm run content:build
```
