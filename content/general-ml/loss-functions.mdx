<TLDR>
A loss function defines what the model must minimize. The right loss matches the task and the noise assumption.
</TLDR>

## Core idea

A loss function gives a scalar cost for a prediction.

For one example:

$$
\ell(\hat y, y).
$$

Training usually minimizes the average loss:

$$
L(\theta)=\frac{1}{n}\sum_{i=1}^n \ell(f_\theta(x_i),y_i).
$$

## Common losses

| Task | Loss |
|---|---|
| Regression | Mean squared error |
| Robust regression | Mean absolute error or Huber loss |
| Binary classification | Binary cross-entropy |
| Multiclass classification | Cross-entropy |
| Margin classification | Hinge loss |

## Mean squared error

Mean squared error is:

$$
\frac{1}{n}\sum_i(\hat y_i-y_i)^2.
$$

It penalizes large errors strongly.

It matches Gaussian noise assumptions.

See <a href="/learn/general-ml/linear-regression">Linear Regression</a>.

## Cross-entropy

For one-hot target $y$ and predicted probabilities $p$:

$$
\ell=-\sum_k y_k\log p_k.
$$

For the correct class $c$:

$$
\ell=-\log p_c.
$$

This is the negative log probability of the correct class.

See <a href="/learn/general-ml/entropy">Entropy</a>.

## Code example

```python
import numpy as np

logits = np.array([[2.0, 1.0, 0.1]])
target = np.array([0])

logits = logits - logits.max(axis=1, keepdims=True)
log_probs = logits - np.log(np.exp(logits).sum(axis=1, keepdims=True))
loss = -log_probs[np.arange(len(target)), target].mean()
```

## Common mistakes

Do not optimize accuracy directly with gradient descent.

Do not apply softmax twice before cross-entropy.

Do not ignore class imbalance.
