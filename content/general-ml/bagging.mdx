<TLDR>
Bagging draws bootstrap samples, fits one base model per sample, and averages the predictions. Averaging reduces variance but leaves bias almost unchanged, so it suits unstable low bias learners such as deep trees. Random forests add feature subsampling to lower the correlation between trees.
</TLDR>

## Algorithm

1. For $b = 1,\dots,B$, draw a bootstrap sample of size $n$ from the training set with replacement.
2. Fit a base model $\hat{f}_b$ on that sample.
3. Average for regression, or vote for classification:

$$
\hat{f}_{\mathrm{bag}}(x) = \frac{1}{B}\sum_{b=1}^{B}\hat{f}_b(x).
$$

The models train independently, so bagging parallelizes perfectly.

## Why averaging reduces variance

<Proof title="Variance of an average of correlated estimators">
Let $\hat{f}_1,\dots,\hat{f}_B$ each have variance $\sigma^2$ and pairwise correlation $\rho$.

The variance of the average is

$$
\operatorname{Var}\left(\frac{1}{B}\sum_{b=1}^{B}\hat{f}_b\right)
=
\frac{1}{B^2}\left[\sum_b \operatorname{Var}(\hat{f}_b)
+ \sum_{b \neq b'}\operatorname{Cov}(\hat{f}_b,\hat{f}_{b'})\right].
$$

There are $B$ variance terms and $B(B-1)$ covariance terms. Each covariance equals $\rho\sigma^2$:

$$
=
\frac{1}{B^2}\big[B\sigma^2 + B(B-1)\rho\sigma^2\big].
$$

Simplify:

$$
=
\rho\sigma^2 + \frac{1-\rho}{B}\sigma^2 .
$$

As $B\to\infty$ the second term vanishes and the variance approaches $\rho\sigma^2$.
</Proof>

Two lessons follow.

1. More models help, but the benefit saturates at $\rho\sigma^2$.
2. Reducing the correlation $\rho$ matters more than adding models once $B$ is large.

## Bias stays the same

Each bootstrap model estimates roughly the same function. So

$$
\mathbb{E}\big[\hat{f}_{\mathrm{bag}}(x)\big]
\approx
\mathbb{E}\big[\hat{f}_b(x)\big].
$$

Bagging therefore does not reduce bias. Use a low bias, high variance base learner such as a fully grown <a href="/learn/general-ml/decision-trees">decision tree</a>.

Bagging a linear model gives almost no gain, because linear fits are already stable.

## Out-of-bag estimate

A bootstrap sample omits some training points.

The probability that a given point is missing from one bootstrap sample is

$$
\left(1-\frac{1}{n}\right)^n \xrightarrow[n\to\infty]{} e^{-1} \approx 0.368 .
$$

So about 36.8 percent of points are out-of-bag for each model.

Predict each training point using only the models that did not see it. The resulting out-of-bag error estimates generalization without a separate validation split. It behaves much like <a href="/learn/general-ml/cross-validation">cross validation</a> at no extra training cost.

## Random forests

A random forest is bagging plus a second source of randomness. At each split the tree considers only a random subset of `max_features` features.

This lowers $\rho$ between trees, so the variance floor $\rho\sigma^2$ drops.

| Setting | Typical value |
|---|---|
| `max_features` for classification | $\sqrt{d}$ |
| `max_features` for regression | $d/3$ |
| `n_estimators` | As many as compute allows |
| `max_depth` | Unlimited or very deep |

More trees never overfit a random forest. They only reduce variance. Depth and feature count control the fit.

Extremely randomized trees push this further. They pick split thresholds at random, which lowers correlation and variance again at a small cost in bias.

## Bagging compared with boosting

| Aspect | Bagging | <a href="/learn/general-ml/boosting">Boosting</a> |
|---|---|---|
| Base learner | Low bias, high variance | High bias, low variance |
| Training | Parallel | Sequential |
| Reduces | Variance | Bias, then variance |
| Overfits with more models | No | Yes |
| Sample weights | Uniform bootstrap | Reweighted by errors |

## Code example

```python
import numpy as np
from sklearn.tree import DecisionTreeRegressor

def bagging_fit(X, y, B=50, seed=0):
    rng = np.random.default_rng(seed)
    n = len(X)
    models, oob_masks = [], []
    for _ in range(B):
        idx = rng.integers(0, n, size=n)
        mask = np.ones(n, dtype=bool)
        mask[np.unique(idx)] = False
        model = DecisionTreeRegressor().fit(X[idx], y[idx])
        models.append(model)
        oob_masks.append(mask)
    return models, oob_masks

def bagging_predict(models, X):
    return np.mean([m.predict(X) for m in models], axis=0)

rng = np.random.default_rng(0)
X = rng.normal(size=(300, 5))
y = X[:, 0] ** 2 + 0.3 * rng.normal(size=300)
models, _ = bagging_fit(X, y)
pred = bagging_predict(models, X)
print(np.mean((pred - y) ** 2))
```

## Common mistakes

Do not bag a high bias model and expect a gain.

Do not sample without replacement and call it bagging. Sampling without replacement is pasting.

Do not treat out-of-bag error as a test score after you tune hyperparameters on it. It then becomes a validation score.
