<TLDR>
Good initialization keeps signal variance stable through layers. Bad initialization can make activations or gradients vanish or explode.
</TLDR>

## Core idea

Neural networks need initial weights before training.

If weights are too small, signals can vanish.

If weights are too large, signals can explode.

Initialization chooses a scale based on layer width.

## Xavier initialization

Xavier initialization is common for tanh-like activations.

For fan-in $n_{\text{in}}$ and fan-out $n_{\text{out}}$:

$$
\operatorname{Var}(W)
=
\frac{2}{n_{\text{in}}+n_{\text{out}}}.
$$

It tries to preserve variance in forward and backward passes.

## He initialization

He initialization is common for ReLU networks.

$$
\operatorname{Var}(W)
=
\frac{2}{n_{\text{in}}}.
$$

ReLU zeros about half the activations under symmetric inputs.

## Symmetry breaking

Do not initialize all weights to the same value.

Equal weights get equal gradients in the same layer.

Random initialization breaks this symmetry.

## Code example

```python
import numpy as np

fan_in = 128
W = np.random.randn(fan_in, 64) * np.sqrt(2.0 / fan_in)
```

## Common mistakes

Do not initialize all weights to zero.

Do not ignore the activation function.

Do not use the same scale for every architecture.
