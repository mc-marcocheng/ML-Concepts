<TLDR>
Linear regression predicts a numeric target with a linear function of features. Ordinary least squares minimizes mean squared error.
</TLDR>

## Core idea

For features $x \in \mathbb{R}^d$, linear regression predicts:

$$
\hat y = x^\top w + b.
$$

For a data matrix $X$ and target vector $y$:

$$
\hat y = Xw.
$$

Assume the bias column is already in $X$.

## Least squares objective

Ordinary least squares minimizes:

$$
L(w)=\frac{1}{2}\|Xw-y\|_2^2.
$$

The gradient is:

$$
\nabla_w L = X^\top(Xw-y).
$$

Set the gradient to zero:

$$
X^\top Xw=X^\top y.
$$

If $X^\top X$ is invertible:

$$
w=(X^\top X)^{-1}X^\top y.
$$

See <a href="/learn/linear-algebra/inverse-of-a-matrix">Inverse of a Matrix</a>.

## Probabilistic view

Linear regression matches maximum likelihood under Gaussian noise.

Assume:

$$
y_i = x_i^\top w + \epsilon_i,
\quad
\epsilon_i \sim \mathcal{N}(0,\sigma^2).
$$

Maximizing likelihood equals minimizing squared error.

See <a href="/learn/general-ml/mle-vs-map">MLE vs MAP</a>.

## Regularization

Ridge regression adds an $L_2$ penalty:

$$
L(w)=\frac{1}{2}\|Xw-y\|_2^2+\frac{\lambda}{2}\|w\|_2^2.
$$

This helps when features are correlated or data is limited.

See <a href="/learn/general-ml/regularization-methods">Regularization Methods</a>.

## Code example

```python
import numpy as np

X = np.c_[np.ones(len(x)), x]
w = np.linalg.solve(X.T @ X, X.T @ y)
pred = X @ w
```

## Common mistakes

Do not assume linear regression means a low-quality model.

Do not invert $X^\top X$ directly when a solver is available.

Do not ignore feature scaling when using regularized regression.
