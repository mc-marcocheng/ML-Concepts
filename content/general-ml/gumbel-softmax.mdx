<TLDR>
The Gumbel-max trick turns categorical sampling into an argmax over logits plus Gumbel noise. Replacing the argmax with a temperature softmax makes the sample differentiable with respect to the logits. Low temperature gives near discrete samples with high gradient variance.
</TLDR>

## The problem

Suppose a network produces logits $\alpha_1,\dots,\alpha_K$ and you sample a category

$$
z \sim \text{Categorical}\left(\pi_k = \frac{e^{\alpha_k}}{\sum_j e^{\alpha_j}}\right).
$$

The sampling step is not differentiable. You cannot backpropagate from a loss on $z$ into $\alpha$.

The score function estimator, also called REINFORCE, works but has high variance:

$$
\nabla_\alpha \mathbb{E}[f(z)]
=
\mathbb{E}\big[f(z)\nabla_\alpha \log p(z)\big].
$$

Gumbel-Softmax gives a low variance biased alternative.

## The Gumbel-max trick

Draw $g_k \sim \text{Gumbel}(0,1)$ independently. The standard Gumbel is generated by

$$
g = -\log(-\log u),
\qquad u \sim \text{Uniform}(0,1).
$$

Then

$$
z = \arg\max_k\ (\alpha_k + g_k)
$$

has exactly the categorical distribution with probabilities $\pi_k \propto e^{\alpha_k}$.

<Proof title="The Gumbel-max trick samples the softmax distribution">
The Gumbel CDF is $F(g) = \exp(-e^{-g})$ and the density is $f(g) = e^{-g}\exp(-e^{-g})$.

Let $Y_k = \alpha_k + g_k$. Compute the probability that index $i$ attains the maximum:

$$
\Pr[i = \arg\max]
=
\int_{-\infty}^{\infty} f(g_i)\prod_{k\neq i}\Pr[\alpha_k + g_k < \alpha_i + g_i]\, dg_i .
$$

For each $k \neq i$,

$$
\Pr[g_k < \alpha_i + g_i - \alpha_k]
=
\exp\big(-e^{-(\alpha_i + g_i - \alpha_k)}\big).
$$

Substitute and write $t = \alpha_i + g_i$:

$$
\Pr[i = \arg\max]
=
\int_{-\infty}^{\infty}
e^{-(t-\alpha_i)}\exp\big(-e^{-(t-\alpha_i)}\big)
\prod_{k\neq i}\exp\big(-e^{-(t-\alpha_k)}\big)\, dt .
$$

Combine all exponential terms, including $k=i$:

$$
=
\int_{-\infty}^{\infty}
e^{\alpha_i}e^{-t}
\exp\left(-e^{-t}\sum_{k=1}^{K}e^{\alpha_k}\right) dt .
$$

Let $S = \sum_k e^{\alpha_k}$ and substitute $v = e^{-t}S$, so $dv = -e^{-t}S\, dt$:

$$
=
\frac{e^{\alpha_i}}{S}\int_{0}^{\infty} e^{-v}\, dv
=
\frac{e^{\alpha_i}}{S}
=
\pi_i .
$$

So the argmax index follows exactly the desired categorical distribution.
</Proof>

The trick separates the randomness, which sits in $g$, from the parameters, which sit in $\alpha$. This is a reparameterization.

## The relaxation

The argmax is still not differentiable. Replace it with a softmax at temperature $\tau > 0$:

$$
y_k
=
\frac{\exp\big((\alpha_k + g_k)/\tau\big)}
{\sum_{j=1}^{K}\exp\big((\alpha_j + g_j)/\tau\big)} .
$$

The vector $y$ lies on the probability simplex and is a smooth function of $\alpha$. This is the Concrete distribution, also called Gumbel-Softmax.

## Temperature

| $\tau$ | Sample shape | Gradient |
|---|---|---|
| $\tau \to 0$ | Approaches a one-hot vector | High variance, matches the discrete sample |
| $\tau$ around 1 | Soft, spread over categories | Low variance, high bias |
| $\tau \to \infty$ | Approaches the uniform vector | Very low variance, useless bias |

There is a direct bias-variance tradeoff. A common practice anneals $\tau$ from about 1.0 down to 0.1 or 0.5 during training.

## Straight-through estimator

Sometimes the forward pass must use a hard one-hot value, such as when the code indexes a table.

The straight-through variant does this.

1. Forward: $y_{\text{hard}} = \text{one hot}(\arg\max_k y_k)$.
2. Backward: pretend the output was the soft $y$ and pass its gradient.

In code this is

```python
y_hard = (y == y.max(dim=-1, keepdim=True).values).float()
y_out = (y_hard - y).detach() + y
```

The value equals `y_hard` in the forward pass. The gradient equals the gradient of `y`, because the detached term contributes none.

This estimator is biased but works well in practice. VQ-VAE uses the same idea for its codebook.

## Where it is used

- Discrete latent variables in <a href="/learn/general-ml/autoencoders">autoencoders</a> and VAEs.
- Neural architecture search, where the choice of operation is categorical.
- Hard attention and discrete routing in mixture of experts.
- Learning to communicate with discrete symbols.

## Code example

```python
import numpy as np

def sample_gumbel(shape, rng, eps=1e-20):
    u = rng.random(shape)
    return -np.log(-np.log(u + eps) + eps)

def gumbel_softmax(logits, tau, rng, hard=False):
    g = sample_gumbel(logits.shape, rng)
    z = (logits + g) / tau
    z = z - z.max(axis=-1, keepdims=True)
    y = np.exp(z)
    y = y / y.sum(axis=-1, keepdims=True)
    if hard:
        idx = y.argmax(axis=-1)
        y_hard = np.zeros_like(y)
        y_hard[np.arange(len(y)), idx] = 1.0
        return y_hard          # forward value only, gradient uses y
    return y

rng = np.random.default_rng(0)
logits = np.tile(np.array([2.0, 1.0, 0.1]), (20000, 1))

for tau in [5.0, 1.0, 0.1]:
    y = gumbel_softmax(logits, tau, rng)
    print(tau, np.round(y.mean(axis=0), 3))

counts = gumbel_softmax(logits, 0.1, rng, hard=True).mean(axis=0)
print("empirical", np.round(counts, 3))
print("target   ", np.round(np.exp(logits[0]) / np.exp(logits[0]).sum(), 3))
```

The hard samples should match the softmax probabilities of the logits.

## Common mistakes

Do not forget the epsilon terms in the Gumbel sampler. A uniform draw of exactly zero produces infinity.

Do not set $\tau$ very small at the start of training. The gradient variance explodes.

Do not expect an unbiased gradient. Gumbel-Softmax trades bias for variance, unlike REINFORCE.

Do not add Gumbel noise at evaluation time when you want the most likely category. Take the argmax of the logits instead.
