<TLDR>
Entropy measures average uncertainty. A uniform distribution has high entropy, while a deterministic distribution has zero entropy.
</TLDR>

## Core idea

For a discrete random variable $X$ with PMF $p(x)$, Shannon entropy is:

$$
H(X)
=
-\sum_x p(x)\log p(x).
$$

Equivalently:

$$
H(X)
=
\mathbb{E}_{X \sim p}[-\log p(X)].
$$

The term $-\log p(x)$ is the information content of outcome $x$.

Rare events have higher information content.

## Units

The log base controls the unit.

| Log base | Unit |
|---|---|
| $2$ | bits |
| $e$ | nats |
| $10$ | bans |

Machine learning usually uses natural logs, so entropy uses nats.

## Simple examples

A deterministic variable has entropy zero.

If $p(x^\star)=1$, then:

$$
H(X)=0.
$$

A uniform distribution over $n$ outcomes has entropy:

$$
H(X)=\log n.
$$

<Proof title="Entropy of a uniform distribution">
For a uniform distribution over $n$ outcomes:

$$
p(x)=\frac{1}{n}.
$$

Then:

$$
H(X)
=
-\sum_{i=1}^{n}\frac{1}{n}\log\frac{1}{n}.
$$

The summand is constant, so:

$$
H(X)
=
-n\frac{1}{n}\log\frac{1}{n}
=
-\log\frac{1}{n}
=
\log n.
$$
</Proof>

## Cross-entropy

Cross-entropy compares data distribution $p$ to model distribution $q$.

$$
H(p,q)
=
-\sum_x p(x)\log q(x).
$$

It is the expected negative log probability under the model.

Many classification losses use cross-entropy.

See <a href="/learn/general-ml/loss-functions">Loss Functions</a> for the optimization view.

## Link to KL divergence

KL divergence is the gap between cross-entropy and entropy.

$$
D_{\mathrm{KL}}(p \Vert q)
=
H(p,q)-H(p).
$$

Thus, minimizing cross-entropy also minimizes KL divergence when $p$ is fixed.

See <a href="/learn/general-ml/kl-divergence">KL Divergence</a> for more.

## Code example

```python
import numpy as np

p = np.array([0.25, 0.25, 0.5])
entropy = -np.sum(p * np.log(p))

print(entropy)
```

## Common mistakes

Do not call entropy the number of classes.

Do not forget the negative sign.

Do not compute $\log 0$ directly. Use masking or clipping in code.
