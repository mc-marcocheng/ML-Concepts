<TLDR>
Activation functions make neural networks nonlinear. Their derivatives strongly affect training.
</TLDR>

## Core idea

Without nonlinear activations, stacked linear layers reduce to one linear map.

An activation function applies after a layer output:

$$
a=\phi(z).
$$

Common activations include ReLU, sigmoid, tanh, GELU, and SiLU.

## ReLU

ReLU is:

$$
\operatorname{ReLU}(z)=\max(0,z).
$$

Its derivative is:

$$
\operatorname{ReLU}'(z)=
\begin{cases}
1 & z>0 \\
0 & z<0
\end{cases}
$$

ReLU is cheap and reduces saturation for positive inputs.

## Sigmoid and tanh

Sigmoid maps values to $(0,1)$:

$$
\sigma(z)=\frac{1}{1+\exp(-z)}.
$$

Tanh maps values to $(-1,1)$.

Both can saturate for large absolute inputs.

Saturation can cause small gradients.

## GELU and SiLU

GELU and SiLU are smooth activations.

They are common in large neural networks.

GELU roughly keeps an input with probability based on its value.

## Code example

```python
import numpy as np

def relu(x):
    return np.maximum(x, 0.0)

def sigmoid(x):
    return 1.0 / (1.0 + np.exp(-x))
```

## Common mistakes

Do not use a final sigmoid before a logits-based binary cross-entropy loss.

Do not use sigmoid in every hidden layer by default.

Do not ignore activation and initialization together.
