<TLDR>
A state space model is a linear recurrence $h_t = \bar{A}h_{t-1} + \bar{B}x_t$. Because it is linear and time invariant, unrolling it gives a convolution with a fixed kernel, which trains in parallel with an FFT. HiPPO initialization and a diagonal plus low rank structure make the kernel cheap and give long memory.
</TLDR>

## Continuous state space model

The model starts from a linear time invariant system:

$$
h'(t) = A h(t) + B x(t),
\qquad
y(t) = C h(t) + D x(t).
$$

Here $h(t)\in\mathbb{R}^N$ is the state, and $x(t)$ and $y(t)$ are scalar per channel.

## Discretization

Sequence data is discrete, so the system must be discretized with a step size $\Delta$.

The zero order hold rule gives

$$
\bar{A} = \exp(\Delta A),
\qquad
\bar{B} = A^{-1}\big(\exp(\Delta A) - I\big)B .
$$

The bilinear rule gives

$$
\bar{A} = \left(I - \tfrac{\Delta}{2}A\right)^{-1}\left(I + \tfrac{\Delta}{2}A\right),
\qquad
\bar{B} = \left(I-\tfrac{\Delta}{2}A\right)^{-1}\Delta B .
$$

The discrete recurrence is then

$$
h_t = \bar{A}h_{t-1} + \bar{B}x_t ,
\qquad
y_t = C h_t .
$$

$\Delta$ is a learned parameter. It sets the time scale that the channel attends to.

## The convolution view

<Proof title="A linear time invariant recurrence unrolls into a convolution">
Start from $h_t = \bar{A}h_{t-1} + \bar{B}x_t$ with $h_{-1}=0$.

Unroll:

$$
h_0 = \bar{B}x_0
$$

$$
h_1 = \bar{A}\bar{B}x_0 + \bar{B}x_1
$$

$$
h_2 = \bar{A}^2\bar{B}x_0 + \bar{A}\bar{B}x_1 + \bar{B}x_2 .
$$

By induction,

$$
h_t = \sum_{j=0}^{t}\bar{A}^{\,t-j}\bar{B}x_j .
$$

Apply the output map $y_t = Ch_t$:

$$
y_t = \sum_{j=0}^{t} C\bar{A}^{\,t-j}\bar{B}\, x_j .
$$

Define the kernel

$$
\bar{K}_k = C\bar{A}^{\,k}\bar{B},
\qquad k = 0,1,2,\dots
$$

Then

$$
y_t = \sum_{j=0}^{t}\bar{K}_{t-j}x_j
=
(\bar{K} * x)_t .
$$

The recurrence is a causal convolution with the fixed kernel $\bar{K}$.
</Proof>

This gives the dual view.

| Mode | Form | Cost | Use |
|---|---|---|---|
| Recurrent | $h_t = \bar{A}h_{t-1}+\bar{B}x_t$ | $O(N)$ per step, $O(N)$ state | Autoregressive generation |
| Convolutional | $y = \bar{K}*x$ | $O(T\log T)$ with FFT | Parallel training |

The same weights serve both modes. This is the key property that RNNs lack.

## The computational problem

Building $\bar{K}$ naively needs powers $\bar{A}^k$ for $k$ up to $T$. That costs $O(N^2 T)$ time and $O(NT)$ memory. It is too slow.

S4 solves this with structure.

## HiPPO initialization

A random $A$ forgets the past quickly. HiPPO derives an $A$ that makes the state an optimal online compression of the input history against a polynomial basis.

The HiPPO-LegS matrix has entries

$$
A_{nk}
=
-\begin{cases}
\sqrt{(2n+1)(2k+1)} & n > k\\
n+1 & n = k\\
0 & n < k .
\end{cases}
$$

With this initialization the state holds coefficients of a Legendre expansion of the recent input. Memory over thousands of steps becomes possible.

## Diagonal plus low rank

The HiPPO matrix is not normal, so it cannot be diagonalized stably. S4 writes it as

$$
A = \Lambda - PQ^\top ,
$$

with $\Lambda$ diagonal and $P,Q$ of low rank. The kernel is then computed in the frequency domain with a Cauchy kernel evaluation. The cost drops to $\tilde{O}(N + T)$.

S4D simplifies further. It drops the low rank term and keeps only a diagonal $\Lambda$ with a good initialization. Performance stays close and the code becomes much simpler.

## S5, Mamba, and selectivity

S4 is linear and time invariant, so the kernel does not depend on the input. That limits content based reasoning.

Mamba makes $\bar{B}$, $C$, and $\Delta$ functions of the input. The system becomes time varying, so the convolution view no longer applies. Mamba instead uses a hardware aware parallel scan to train in parallel.

This selectivity lets the model choose what to keep and what to skip, which closes much of the gap with attention on language tasks.

## Comparison

| Property | <a href="/learn/general-ml/rnns-lstms">LSTM</a> | Transformer | S4 |
|---|---|---|---|
| Training parallel over time | No | Yes | Yes |
| Train cost in $T$ | $O(T)$ sequential | $O(T^2)$ | $O(T\log T)$ |
| Inference state | $O(H)$ | $O(T)$ KV cache | $O(N)$ |
| Long range benchmark | Weak | Moderate | Strong |
| Content based selection | Yes | Yes | No, unless selective |

S4 set the first strong results on the Long Range Arena benchmark, including the Path-X task that transformers failed.

## Code example

```python
import numpy as np

def ssm_kernel(A_bar, B_bar, C, L):
    """Build the convolution kernel K_k = C A_bar^k B_bar for k < L."""
    N = A_bar.shape[0]
    K = np.zeros(L)
    Ak_B = B_bar.copy()
    for k in range(L):
        K[k] = float(C @ Ak_B)
        Ak_B = A_bar @ Ak_B
    return K

def ssm_conv(K, x):
    """Causal convolution via FFT."""
    L = len(x)
    n = 2 * L
    y = np.fft.irfft(np.fft.rfft(K, n) * np.fft.rfft(x, n), n)
    return y[:L]

def ssm_recurrent(A_bar, B_bar, C, x):
    h = np.zeros(A_bar.shape[0])
    out = np.zeros(len(x))
    for t, xt in enumerate(x):
        h = A_bar @ h + B_bar.ravel() * xt
        out[t] = float(C @ h)
    return out

rng = np.random.default_rng(0)
N, L = 8, 64
A_bar = np.diag(rng.uniform(0.7, 0.99, size=N))
B_bar = rng.normal(size=(N, 1)) * 0.1
C = rng.normal(size=(1, N)) * 0.1
x = rng.normal(size=L)

K = ssm_kernel(A_bar, B_bar, C, L)
print(np.max(np.abs(ssm_conv(K, x) - ssm_recurrent(A_bar, B_bar, C, x))))
```

The two modes agree to numerical precision. That is the dual view in one check.

## Common mistakes

Do not initialize $A$ randomly. The HiPPO structure is what gives long memory.

Do not build the kernel by explicit matrix powers at training time. Use the structured frequency domain computation.

Do not forget that plain S4 is time invariant. It cannot select content the way attention can.

Do not confuse the state dimension $N$ with the model width. Each channel carries its own small state.
