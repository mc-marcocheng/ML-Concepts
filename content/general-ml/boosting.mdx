<TLDR>
Boosting builds an additive model one weak learner at a time. AdaBoost reweights misclassified examples. Gradient boosting fits each new tree to the negative gradient of the loss. Boosting cuts bias, so more rounds can overfit.
</TLDR>

## Additive model

Boosting produces

$$
F_M(x) = \sum_{m=1}^{M}\nu\, h_m(x),
$$

where each $h_m$ is a weak learner and $\nu$ is the learning rate. A weak learner performs only slightly better than chance. A depth 2 to 8 <a href="/learn/general-ml/decision-trees">tree</a> is the usual choice.

## AdaBoost

AdaBoost handles binary labels $y_i \in \{-1,+1\}$.

1. Initialize weights $w_i = 1/n$.
2. For $m = 1,\dots,M$:
   - Fit $h_m$ on the weighted data.
   - Compute the weighted error $\epsilon_m = \sum_i w_i \mathbb{1}[h_m(x_i)\neq y_i]$.
   - Set $\alpha_m = \tfrac{1}{2}\log\frac{1-\epsilon_m}{\epsilon_m}$.
   - Update $w_i \leftarrow w_i \exp(-\alpha_m y_i h_m(x_i))$ and renormalize.
3. Predict $\operatorname{sign}\left(\sum_m \alpha_m h_m(x)\right)$.

<Proof title="AdaBoost minimizes exponential loss and gives the alpha formula">
AdaBoost performs forward stagewise minimization of the exponential loss

$$
L(F) = \sum_{i=1}^{n}\exp\big(-y_i F(x_i)\big).
$$

Suppose the current model is $F_{m-1}$. Add a term $\alpha h$:

$$
L(\alpha, h)
=
\sum_i \exp\big(-y_i F_{m-1}(x_i)\big)\exp\big(-\alpha y_i h(x_i)\big).
$$

Define the weights $w_i = \exp(-y_i F_{m-1}(x_i))$. Since $y_i h(x_i) \in \{-1,+1\}$,

$$
L(\alpha,h)
=
e^{-\alpha}\sum_{i:\,h(x_i)=y_i} w_i
+
e^{\alpha}\sum_{i:\,h(x_i)\neq y_i} w_i .
$$

Let $\epsilon = \frac{\sum_{i: h(x_i)\neq y_i} w_i}{\sum_i w_i}$ be the normalized weighted error. Divide by $\sum_i w_i$:

$$
\tilde{L}(\alpha)
=
e^{-\alpha}(1-\epsilon) + e^{\alpha}\epsilon .
$$

Differentiate with respect to $\alpha$:

$$
\frac{d\tilde{L}}{d\alpha}
=
-e^{-\alpha}(1-\epsilon) + e^{\alpha}\epsilon = 0 .
$$

So

$$
e^{2\alpha} = \frac{1-\epsilon}{\epsilon},
\qquad
\alpha = \tfrac{1}{2}\log\frac{1-\epsilon}{\epsilon}.
$$

The weight update $w_i \leftarrow w_i e^{-\alpha y_i h(x_i)}$ is exactly the new value of $\exp(-y_i F_m(x_i))$ up to a constant. This proves the algorithm.
</Proof>

Note that $\alpha_m$ is positive when $\epsilon_m < 0.5$ and grows as the error falls.

## Gradient boosting

Gradient boosting generalizes the idea to any differentiable loss $\ell$.

Treat the ensemble output $F(x_i)$ as a parameter. Perform gradient descent in function space.

1. Initialize $F_0(x) = \arg\min_c \sum_i \ell(y_i, c)$.
2. For $m=1,\dots,M$:
   - Compute pseudo-residuals

     $$
     r_{im} = -\left[\frac{\partial \ell(y_i, F(x_i))}{\partial F(x_i)}\right]_{F=F_{m-1}} .
     $$

   - Fit a regression tree $h_m$ to the pairs $(x_i, r_{im})$.
   - Set the leaf values by a line search on the loss.
   - Update $F_m = F_{m-1} + \nu h_m$.

For squared loss $\ell = \tfrac{1}{2}(y-F)^2$, the pseudo-residual is exactly $y_i - F_{m-1}(x_i)$. Each tree then fits the current residual.

| Loss | Pseudo-residual |
|---|---|
| Squared error | $y_i - F(x_i)$ |
| Absolute error | $\operatorname{sign}(y_i - F(x_i))$ |
| Logistic (binary) | $y_i - \sigma(F(x_i))$ |
| Exponential | Recovers AdaBoost |

## Second order boosting

XGBoost uses a second order expansion. For each example define

$$
g_i = \frac{\partial \ell}{\partial F(x_i)},
\qquad
h_i = \frac{\partial^2 \ell}{\partial F(x_i)^2}.
$$

The regularized objective for one tree with leaves $j$ and leaf values $w_j$ is

$$
\mathcal{L}
=
\sum_j \left[\left(\sum_{i\in I_j} g_i\right)w_j
+ \tfrac{1}{2}\left(\sum_{i\in I_j} h_i + \lambda\right)w_j^2\right]
+ \gamma T .
$$

Minimize over $w_j$:

$$
w_j^\star = -\frac{\sum_{i\in I_j} g_i}{\sum_{i\in I_j} h_i + \lambda},
$$

and the resulting leaf score is

$$
-\tfrac{1}{2}\frac{\left(\sum_{i\in I_j} g_i\right)^2}{\sum_{i\in I_j} h_i + \lambda}.
$$

The split gain compares the parent score with the sum of the two child scores minus $\gamma$. A split with a negative gain is rejected.

## Regularization

| Control | Effect |
|---|---|
| Learning rate $\nu$ | Shrinks each step. Small $\nu$ needs more rounds and generalizes better |
| Number of rounds $M$ | Main capacity dial. Use early stopping |
| Tree depth | Limits interaction order |
| Subsample rows | Stochastic gradient boosting, adds variance reduction |
| Subsample columns | Reduces correlation between trees |
| $\lambda$ and $\gamma$ | L2 on leaf values and per leaf penalty |
| `min_child_weight` | Requires enough Hessian mass per leaf |

A common rule sets $\nu$ around 0.05 and picks $M$ by <a href="/learn/general-ml/early-stopping">early stopping</a> on a validation set.

## Boosting versus bagging

| Aspect | Boosting | <a href="/learn/general-ml/bagging">Bagging</a> |
|---|---|---|
| Base learner | Weak, high bias | Strong, high variance |
| Order | Sequential | Parallel |
| Main effect | Reduces bias | Reduces variance |
| More models | Can overfit | Cannot overfit |
| Noise robustness | Lower, AdaBoost chases outliers | Higher |

## Code example

```python
import numpy as np
from sklearn.tree import DecisionTreeRegressor

def gradient_boost(X, y, rounds=100, lr=0.1, depth=3):
    F = np.full(len(y), y.mean())
    trees = []
    for _ in range(rounds):
        residual = y - F              # squared loss pseudo-residual
        tree = DecisionTreeRegressor(max_depth=depth).fit(X, residual)
        F = F + lr * tree.predict(X)
        trees.append(tree)
    return y.mean(), trees

def gb_predict(base, trees, X, lr=0.1):
    out = np.full(len(X), base)
    for t in trees:
        out += lr * t.predict(X)
    return out

rng = np.random.default_rng(0)
X = rng.normal(size=(400, 4))
y = np.sin(X[:, 0]) + X[:, 1] ** 2 + 0.1 * rng.normal(size=400)
base, trees = gradient_boost(X, y)
print(np.mean((gb_predict(base, trees, X) - y) ** 2))
```

## Common mistakes

Do not raise the learning rate to save time. Lower the rate and add rounds instead.

Do not fit boosting to heavily mislabeled data without care. AdaBoost gives huge weight to persistent errors.

Do not forget that gradient boosting fits a regression tree even for classification. The tree fits gradients, not classes.
