<TLDR>
Precision asks how many predicted positives are correct. Recall asks how many actual positives you found. F1 is their harmonic mean. ROC-AUC measures ranking quality across all thresholds and ignores class balance, while PR-AUC reflects it.
</TLDR>

## Confusion matrix

|  | Predicted positive | Predicted negative |
|---|---|---|
| **Actual positive** | TP | FN |
| **Actual negative** | FP | TN |

A false positive is a type I error. A false negative is a type II error.

## Core metrics

$$
\text{Accuracy} = \frac{TP+TN}{TP+TN+FP+FN}
$$

$$
\text{Precision} = \frac{TP}{TP+FP}
$$

$$
\text{Recall} = \text{TPR} = \frac{TP}{TP+FN}
$$

$$
\text{Specificity} = \text{TNR} = \frac{TN}{TN+FP}
$$

$$
\text{FPR} = \frac{FP}{FP+TN} = 1 - \text{Specificity}
$$

Precision has predicted positives in the denominator. Recall has actual positives in the denominator. That is the whole difference.

Accuracy fails under class imbalance. A model that always predicts the majority class reaches 99 percent accuracy on a 1 percent positive rate, with zero recall.

## F1 and F-beta

$$
F_1
=
\frac{2\,\text{Precision}\cdot\text{Recall}}{\text{Precision}+\text{Recall}} .
$$

This is the harmonic mean. The harmonic mean punishes an imbalance. A model with precision 1.0 and recall 0.01 has $F_1 \approx 0.02$, while the arithmetic mean would give 0.5.

The general form weights recall by $\beta$:

$$
F_\beta
=
(1+\beta^2)\frac{\text{Precision}\cdot\text{Recall}}
{\beta^2\,\text{Precision}+\text{Recall}} .
$$

$\beta = 2$ weights recall higher, as in disease screening. $\beta = 0.5$ weights precision higher, as in spam filtering where a false positive is costly.

Note that F1 ignores true negatives entirely.

## Threshold and tradeoff

A scoring model outputs $s(x) \in [0,1]$. The predicted label is $\mathbb{1}[s(x) \ge \tau]$.

Raising $\tau$ raises precision and lowers recall. Lowering $\tau$ does the opposite.

Metrics such as precision and recall are threshold dependent. ROC-AUC and PR-AUC are threshold free.

## ROC curve and AUC

The ROC curve plots TPR against FPR as $\tau$ sweeps from 1 to 0.

- The diagonal is a random ranker with AUC 0.5.
- The top left corner is a perfect ranker with AUC 1.0.
- AUC below 0.5 means the scores are anti-correlated with the labels.

<Proof title="AUC equals the probability that a random positive outscores a random negative">
Let $S^+$ be the score of a random positive example and $S^-$ the score of a random negative example, drawn independently.

Fix a threshold $\tau$. Then

$$
\mathrm{TPR}(\tau) = \Pr[S^+ \ge \tau],
\qquad
\mathrm{FPR}(\tau) = \Pr[S^- \ge \tau].
$$

Let $F_-$ be the cumulative distribution of $S^-$. Then $\mathrm{FPR} = 1 - F_-(\tau)$ and $d(\mathrm{FPR}) = -f_-(\tau)\,d\tau$.

The area under the curve is

$$
\mathrm{AUC}
=
\int_0^1 \mathrm{TPR}\; d(\mathrm{FPR})
=
\int_{-\infty}^{\infty}\Pr[S^+ \ge \tau]\, f_-(\tau)\, d\tau .
$$

The inner probability is an expectation of an indicator:

$$
=
\int_{-\infty}^{\infty}\mathbb{E}\big[\mathbb{1}[S^+\ge \tau]\big] f_-(\tau)\,d\tau
=
\mathbb{E}_{S^-}\Big[\Pr[S^+ \ge S^-]\Big].
$$

Since $S^+$ and $S^-$ are independent,

$$
\mathrm{AUC} = \Pr\big[S^+ > S^-\big] + \tfrac{1}{2}\Pr\big[S^+ = S^-\big].
$$

So AUC is the probability that the model ranks a random positive above a random negative, with ties counted as half.
</Proof>

This is why AUC equals the normalized Mann-Whitney U statistic.

## Precision-recall curve

The PR curve plots precision against recall.

A random classifier gives a flat PR curve at the positive rate $\pi$. So the baseline for PR-AUC depends on class balance, while the ROC baseline is always 0.5.

| Situation | Prefer |
|---|---|
| Balanced classes | ROC-AUC |
| Rare positive class | PR-AUC |
| You care about both classes equally | ROC-AUC |
| You care only about the positive class | PR-AUC |

ROC-AUC can look strong on a heavily imbalanced problem, because a large TN count keeps FPR small even with many false positives. PR-AUC exposes this.

## Multiclass averaging

| Average | Definition | When |
|---|---|---|
| Macro | Mean of per class scores | All classes matter equally |
| Micro | Pool all TP, FP, FN, then compute | Frequency weighted, equals accuracy for single label problems |
| Weighted | Mean weighted by class support | Reports a frequency aware summary |

## Choosing a metric

1. Write down the cost of a false positive and a false negative.
2. Pick the metric that reflects those costs.
3. Tune the threshold on a validation split, not on the test set.
4. Report the metric with a confidence interval. See <a href="/learn/general-ml/confidence-intervals">confidence intervals</a>.

## Code example

```python
import numpy as np

def confusion(y_true, y_pred):
    tp = np.sum((y_true == 1) & (y_pred == 1))
    fp = np.sum((y_true == 0) & (y_pred == 1))
    fn = np.sum((y_true == 1) & (y_pred == 0))
    tn = np.sum((y_true == 0) & (y_pred == 0))
    return tp, fp, fn, tn

def prf(y_true, y_pred):
    tp, fp, fn, _ = confusion(y_true, y_pred)
    precision = tp / (tp + fp) if tp + fp else 0.0
    recall = tp / (tp + fn) if tp + fn else 0.0
    denom = precision + recall
    f1 = 2 * precision * recall / denom if denom else 0.0
    return precision, recall, f1

def auc_rank(y_true, scores):
    """AUC as the probability a positive outranks a negative."""
    pos = scores[y_true == 1]
    neg = scores[y_true == 0]
    comp = (pos[:, None] > neg[None, :]).sum() + 0.5 * (pos[:, None] == neg[None, :]).sum()
    return comp / (len(pos) * len(neg))

rng = np.random.default_rng(0)
y = rng.integers(0, 2, size=500)
s = rng.random(500) * 0.5 + 0.5 * y
print(prf(y, (s > 0.5).astype(int)), round(float(auc_rank(y, s)), 3))
```

## Common mistakes

Do not report accuracy alone on imbalanced data.

Do not tune the threshold on the test set.

Do not compare PR-AUC values across datasets with different positive rates. The baseline moves.

Do not confuse recall with precision. Check which denominator you need.
