<TLDR>
A support vector machine maximizes the distance from the decision boundary to the closest points. The soft margin form is a convex quadratic program equal to hinge loss plus L2 regularization. The dual depends on data only through inner products, which allows kernels.
</TLDR>

## Margin

Take labels $y_i \in \{-1,+1\}$ and a hyperplane $w^\top x + b = 0$.

The signed distance from $x_i$ to the hyperplane is

$$
\frac{y_i(w^\top x_i + b)}{\|w\|}.
$$

Fix the scale so the closest points satisfy $y_i(w^\top x_i + b) = 1$. This is the canonical form.

<Proof title="The margin width equals two over the norm of w">
Let $x_+$ satisfy $w^\top x_+ + b = 1$ and let $x_-$ satisfy $w^\top x_- + b = -1$.

Subtract the two equations:

$$
w^\top (x_+ - x_-) = 2 .
$$

The distance between the two supporting hyperplanes is the length of the projection of $x_+ - x_-$ onto the unit normal $w/\|w\|$:

$$
\frac{w^\top (x_+ - x_-)}{\|w\|}
=
\frac{2}{\|w\|}.
$$

So maximizing the margin $2/\|w\|$ is the same as minimizing $\tfrac{1}{2}\|w\|^2$.
</Proof>

## Hard margin primal

$$
\min_{w,b}\ \tfrac{1}{2}\|w\|^2
\quad \text{subject to} \quad
y_i(w^\top x_i + b) \ge 1 \ \ \forall i .
$$

This is a convex quadratic program. It has no solution when the data is not linearly separable.

## Soft margin primal

Add slack variables $\xi_i \ge 0$:

$$
\min_{w,b,\xi}\ \tfrac{1}{2}\|w\|^2 + C\sum_{i=1}^{n}\xi_i
\quad \text{subject to} \quad
y_i(w^\top x_i + b) \ge 1 - \xi_i,\ \ \xi_i \ge 0 .
$$

At the optimum $\xi_i = \max(0, 1 - y_i(w^\top x_i + b))$. So the problem is equivalent to

$$
\min_{w,b}\ \sum_{i=1}^{n}\max\big(0,\ 1 - y_i(w^\top x_i+b)\big)
+ \frac{1}{2C}\|w\|^2 .
$$

This is hinge loss plus <a href="/learn/general-ml/regularisation-methods">L2 regularization</a>.

$C$ controls the tradeoff. A large $C$ punishes violations hard and gives a narrow margin. A small $C$ allows violations and gives a wide margin.

## Dual form

Introduce multipliers $\alpha_i \ge 0$. The dual is

$$
\max_{\alpha}\ \sum_{i=1}^{n}\alpha_i
-\tfrac{1}{2}\sum_{i,j}\alpha_i\alpha_j y_i y_j\, x_i^\top x_j
$$

subject to

$$
0 \le \alpha_i \le C,
\qquad
\sum_{i=1}^{n}\alpha_i y_i = 0 .
$$

The weight vector is

$$
w = \sum_{i=1}^{n}\alpha_i y_i x_i .
$$

Two facts follow.

1. The data enters only through inner products $x_i^\top x_j$.
2. Only points with $\alpha_i > 0$ contribute. These are the support vectors.

## KKT conditions

| Condition | Meaning |
|---|---|
| $\alpha_i = 0$ | Point is outside the margin and correctly classified |
| $0 < \alpha_i < C$ | Point sits exactly on the margin |
| $\alpha_i = C$ | Point violates the margin or is misclassified |

Removing a non-support vector does not change the solution.

## Kernels

Replace the inner product with a kernel $k(x,x') = \phi(x)^\top\phi(x')$. The dual becomes

$$
\max_\alpha \sum_i \alpha_i - \tfrac{1}{2}\sum_{i,j}\alpha_i\alpha_j y_i y_j\, k(x_i,x_j).
$$

The prediction is

$$
f(x) = \sum_{i}\alpha_i y_i\, k(x_i, x) + b .
$$

You never compute $\phi$ explicitly. This is the kernel trick.

| Kernel | Formula |
|---|---|
| Linear | $x^\top x'$ |
| Polynomial | $(\gamma x^\top x' + r)^p$ |
| RBF | $\exp(-\gamma\|x-x'\|^2)$ |
| Sigmoid | $\tanh(\gamma x^\top x' + r)$ |

A valid kernel produces a <a href="/learn/linear-algebra/positive-semi-definite">positive semi-definite</a> Gram matrix. This is Mercer's condition.

The RBF kernel maps to an infinite dimensional space. A large $\gamma$ makes each point influence only its immediate area, which risks overfitting.

## Regression and multiclass

Support vector regression uses an $\epsilon$-insensitive loss. Errors smaller than $\epsilon$ cost nothing.

SVMs are binary by design. Multiclass uses one-vs-rest or one-vs-one.

## Practical notes

- Scale the features. The RBF kernel and the regularizer both depend on scale.
- Tune $C$ and $\gamma$ together on a log grid with <a href="/learn/general-ml/cross-validation">cross validation</a>.
- Training cost is between $O(n^2)$ and $O(n^3)$ for kernel SVMs, so they suit medium sized data.
- A linear SVM on large sparse data trains fast with `LinearSVC` or SGD on the hinge loss.

## Code example

```python
import numpy as np

def hinge_sgd(X, y, C=1.0, lr=0.01, epochs=200, seed=0):
    """y in {-1, +1}. Minimizes 0.5||w||^2 + C * sum(hinge)."""
    rng = np.random.default_rng(seed)
    n, d = X.shape
    w = np.zeros(d)
    b = 0.0
    for _ in range(epochs):
        for i in rng.permutation(n):
            margin = y[i] * (X[i] @ w + b)
            if margin < 1:
                w = w - lr * (w - C * y[i] * X[i])
                b = b + lr * C * y[i]
            else:
                w = w - lr * w
    return w, b

rng = np.random.default_rng(0)
X = rng.normal(size=(200, 2))
y = np.where(X[:, 0] + X[:, 1] > 0, 1, -1)
w, b = hinge_sgd(X, y)
print(np.mean(np.sign(X @ w + b) == y))
```

## Common mistakes

Do not forget that SVM labels are $-1$ and $+1$, not $0$ and $1$.

Do not use an RBF kernel on unscaled features.

Do not read $C$ as a regularization strength. A large $C$ means weak regularization.
