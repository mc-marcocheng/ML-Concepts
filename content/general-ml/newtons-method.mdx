<TLDR>
Newton's method uses a local quadratic approximation. Its step solves a linear system with the Hessian.
</TLDR>

## Core idea

For scalar root finding, Newton's method updates:

$$
x_{t+1}
=
x_t-\frac{f(x_t)}{f'(x_t)}.
$$

For optimization, apply Newton's method to the gradient.

Let $g=\nabla L(\theta)$ and $H=\nabla^2L(\theta)$.

The Newton step is:

$$
\theta_{t+1}
=
\theta_t-H^{-1}g.
$$

## Quadratic approximation

Use the local approximation:

$$
L(\theta+\Delta)
\approx
L(\theta)+g^\top\Delta+\frac{1}{2}\Delta^\top H\Delta.
$$

Minimize with respect to $\Delta$.

The gradient is:

$$
g+H\Delta.
$$

Set it to zero:

$$
H\Delta=-g.
$$

Thus:

$$
\Delta=-H^{-1}g.
$$

## Practical issues

The Hessian can be large.

The Hessian can be singular or indefinite.

Many systems solve $H\Delta=-g$ instead of forming $H^{-1}$.

See <a href="/learn/general-ml/second-order-methods">Second Order Methods</a>.

## Code example

```python
import numpy as np

delta = np.linalg.solve(H, -g)
theta = theta + delta
```

The ridge term keeps the Hessian invertible when the data is separable.

## Common mistakes

Do not compute an explicit inverse when a solve is available.

Do not assume the Hessian is positive definite.

Do not use Newton's method without damping when steps are unstable.
