<TLDR>
An ensemble combines several predictors by averaging, voting, or stacking. The ambiguity decomposition shows the ensemble error equals the average member error minus the disagreement between members. So diversity is the resource that makes ensembles work.
</TLDR>

## Combination methods

| Method | How it combines | Notes |
|---|---|---|
| Averaging | Mean of the outputs | Standard for regression and probabilities |
| Hard voting | Majority class | Needs an odd count to avoid ties |
| Soft voting | Mean of predicted probabilities | Usually better than hard voting |
| Weighted average | Weights from validation performance | Risk of overfitting the weights |
| Stacking | A meta model learns the combination | Strongest, needs out-of-fold predictions |
| <a href="/learn/general-ml/bagging">Bagging</a> | Bootstrap resamples, then average | Reduces variance |
| <a href="/learn/general-ml/boosting">Boosting</a> | Sequential correction | Reduces bias |

## Ambiguity decomposition

For squared loss and a simple average, the ensemble error decomposes exactly.

<Proof title="Ambiguity decomposition for a uniform average">
Let the members be $f_1,\dots,f_M$ and let

$$
\bar{f}(x) = \frac{1}{M}\sum_{m=1}^{M} f_m(x).
$$

Fix a target $y$. Consider the average member error:

$$
\frac{1}{M}\sum_m (f_m - y)^2 .
$$

Write $f_m - y = (f_m - \bar{f}) + (\bar{f} - y)$ and expand:

$$
\frac{1}{M}\sum_m (f_m - y)^2
=
\frac{1}{M}\sum_m (f_m-\bar{f})^2
+ 2(\bar{f}-y)\frac{1}{M}\sum_m (f_m-\bar{f})
+ (\bar{f}-y)^2 .
$$

The middle sum is zero because $\bar{f}$ is the mean of the $f_m$.

Therefore

$$
(\bar{f}-y)^2
=
\frac{1}{M}\sum_m (f_m - y)^2
-
\frac{1}{M}\sum_m (f_m-\bar{f})^2 .
$$

The ensemble error equals the average member error minus the ambiguity, which is the variance of the members around their own mean.
</Proof>

Two conclusions follow.

1. The ensemble is never worse than the average member for squared loss.
2. Larger disagreement between members lowers the ensemble error, provided the average member error does not rise as much.

## Where diversity comes from

- Different bootstrap samples. See bagging.
- Different feature subsets. See random forests.
- Different random seeds and initializations. This alone works for neural networks.
- Different model families, such as a tree ensemble plus a linear model plus a neural network.
- Different hyperparameters.
- Different data views or augmentations.

Deep ensembles that differ only in the random seed already give strong gains, because the loss surface has many distinct minima.

## Stacking

Stacking trains a meta model on the predictions of the base models.

1. Split the training data into $K$ folds.
2. For each fold, train the base models on the other folds and predict the held out fold. This produces out-of-fold predictions for every training row.
3. Train the meta model on those out-of-fold predictions.
4. Retrain each base model on all the data for test time prediction.

Step 2 is critical. Using in-sample base predictions leaks information and makes the meta model trust an overfitted base model.

The meta model is usually simple, such as ridge regression or logistic regression.

## Cost and value

| Aspect | Effect |
|---|---|
| Training cost | Multiplied by the member count |
| Inference cost | Multiplied by the member count |
| Memory | Multiplied by the member count |
| Accuracy | Usually a small but reliable gain |
| Calibration | Averaging often improves probability calibration |
| Uncertainty | The spread of members estimates uncertainty |

Knowledge distillation trains a single student to match the ensemble output. It keeps most of the accuracy at one model of inference cost.

## Code example

```python
import numpy as np
from sklearn.linear_model import RidgeCV
from sklearn.model_selection import KFold

def stack_oof(models, X, y, k=5, seed=0):
    kf = KFold(n_splits=k, shuffle=True, random_state=seed)
    oof = np.zeros((len(X), len(models)))
    for tr, va in kf.split(X):
        for j, m in enumerate(models):
            m.fit(X[tr], y[tr])
            oof[va, j] = m.predict(X[va])
    meta = RidgeCV().fit(oof, y)
    for m in models:
        m.fit(X, y)
    return meta, models

def stack_predict(meta, models, X):
    base = np.column_stack([m.predict(X) for m in models])
    return meta.predict(base)
```

## Common mistakes

Do not build an ensemble of near identical models. The correlation is high and the gain is small.

Do not fit stacking weights on in-sample base predictions.

Do not report an ensemble gain without checking the extra inference cost against the requirement.
