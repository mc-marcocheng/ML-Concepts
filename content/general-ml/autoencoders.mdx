<TLDR>
An autoencoder pairs an encoder $z=f(x)$ with a decoder $\hat{x}=g(z)$ and minimizes reconstruction error. A linear autoencoder with squared loss recovers the PCA subspace. Denoising, sparse, and contractive variants add constraints so that the code captures structure rather than identity.
</TLDR>

## Basic form

$$
z = f_\theta(x),
\qquad
\hat{x} = g_\phi(z),
\qquad
\mathcal{L} = \frac{1}{n}\sum_{i=1}^{n}\|x_i - g_\phi(f_\theta(x_i))\|^2 .
$$

The code $z$ has lower dimension than $x$ in the undercomplete case. That bottleneck forces the network to keep only what matters for reconstruction.

The training signal comes from the input itself, so no labels are needed.

## Relation to PCA

<Proof title="A linear autoencoder with squared loss spans the principal subspace">
Let the encoder and decoder be linear with no bias, so $z = Wx$ and $\hat{x} = Vz = VWx$, with $W \in \mathbb{R}^{k\times d}$ and $V\in\mathbb{R}^{d\times k}$.

Assume the data is centered. The objective is

$$
\min_{V,W}\ \mathbb{E}\big[\|x - VWx\|^2\big].
$$

Let $M = VW$. Since $V$ and $W$ have inner dimension $k$, the matrix $M$ has rank at most $k$. Any rank $k$ matrix can be factored this way, so the problem is

$$
\min_{\operatorname{rank}(M)\le k}\ \mathbb{E}\big[\|x - Mx\|^2\big].
$$

Write the objective with the covariance $\Sigma = \mathbb{E}[xx^\top]$:

$$
\mathbb{E}\big[\|(I-M)x\|^2\big]
=
\operatorname{tr}\big((I-M)\Sigma(I-M)^\top\big).
$$

By the Eckart-Young theorem, the best rank $k$ approximation in this sense is the orthogonal projection onto the span of the top $k$ eigenvectors of $\Sigma$. So

$$
M^\star = U_k U_k^\top ,
$$

where $U_k$ holds the top $k$ eigenvectors.

Therefore the optimal $W$ has row space equal to the top $k$ principal subspace. The individual rows need not be the principal components, because any invertible $k\times k$ change of basis $R$ gives the same product through $W' = RW$ and $V' = VR^{-1}$.
</Proof>

So a linear autoencoder finds the same subspace as <a href="/learn/general-ml/dimensionality-reduction">PCA</a> but not the same axes. Nonlinear encoders can capture curved manifolds that PCA cannot.

## Denoising autoencoder

Corrupt the input, then ask for the clean target:

$$
\tilde{x} \sim q(\tilde{x}\mid x),
\qquad
\mathcal{L} = \mathbb{E}\big[\|x - g(f(\tilde{x}))\|^2\big].
$$

Common corruptions are additive Gaussian noise, random masking, and dropout on the input.

The model cannot copy the input, so it must learn the data structure that lets it fill in missing parts. A denoising autoencoder with small Gaussian noise learns a function proportional to the score $\nabla_x \log p(x)$, which links it to diffusion models.

Masked prediction in modern pretraining is a denoising autoencoder with token masking.

## Sparse autoencoder

Add a penalty that keeps most code units near zero:

$$
\mathcal{L} = \|x-\hat{x}\|^2 + \lambda\|z\|_1 ,
$$

or a KL penalty toward a small target activation $\rho$:

$$
\sum_{j}\rho\log\frac{\rho}{\hat{\rho}_j} + (1-\rho)\log\frac{1-\rho}{1-\hat{\rho}_j}.
$$

Sparsity allows an overcomplete code, where $\dim(z) > \dim(x)$, without collapsing to the identity. Sparse autoencoders are now widely used to find interpretable features inside language model activations.

## Contractive autoencoder

Penalize the sensitivity of the code to input changes:

$$
\mathcal{L} = \|x-\hat{x}\|^2 + \lambda\left\|\frac{\partial f(x)}{\partial x}\right\|_F^2 .
$$

The <a href="/learn/linear-algebra/jacobian">Jacobian</a> penalty makes the representation flat in directions that leave the data manifold and responsive along the manifold.

## Variational autoencoder

A VAE is a generative model, not just a compressor. The encoder outputs a distribution $q_\phi(z\mid x)$ and the objective is the evidence lower bound:

$$
\mathcal{L}_{\text{ELBO}}
=
\mathbb{E}_{q_\phi(z\mid x)}\big[\log p_\theta(x\mid z)\big]
- D_{\mathrm{KL}}\big(q_\phi(z\mid x)\,\|\,p(z)\big).
$$

The KL term regularizes the latent space so that sampling from the prior produces valid outputs. A plain autoencoder has no such guarantee and its latent space contains holes.

## Uses and limits

| Use | Note |
|---|---|
| Nonlinear dimensionality reduction | Parametric, applies to new points |
| Anomaly detection | Flag high reconstruction error |
| Denoising and inpainting | Direct application of the training task |
| Pretraining | Masked autoencoders for vision and text |
| Discrete codes | VQ-VAE for tokenizing images and audio |

Limits:

- A plain autoencoder can learn a near identity map if the capacity is too large.
- Reconstruction error is not the same as usefulness for a downstream task.
- Squared loss produces blurry image outputs.

## Code example

```python
import numpy as np

def linear_ae_grads(X, W, V):
    """Squared reconstruction loss for z = W x, xhat = V z."""
    Z = X @ W.T
    Xh = Z @ V.T
    E = Xh - X
    n = len(X)
    loss = np.mean(np.sum(E ** 2, axis=1))
    gV = 2.0 / n * E.T @ Z
    gW = 2.0 / n * (E @ V).T @ X
    return loss, gW, gV

rng = np.random.default_rng(0)
base = rng.normal(size=(400, 2))
X = base @ rng.normal(size=(2, 8))
X = X - X.mean(0)

W = rng.normal(size=(2, 8)) * 0.1
V = rng.normal(size=(8, 2)) * 0.1
for step in range(3000):
    loss, gW, gV = linear_ae_grads(X, W, V)
    W -= 0.01 * gW
    V -= 0.01 * gV
print(round(float(loss), 6))
```

The loss should approach zero, because the data has rank two and the code has size two.

## Common mistakes

Do not give a plain autoencoder a bottleneck as large as the input without a regularizer. It will learn the identity.

Do not treat a plain autoencoder latent space as a generative prior. Use a VAE for that.

Do not compare reconstruction losses across models with different input scaling.
