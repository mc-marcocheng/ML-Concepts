<TLDR>
Temporal-difference learning updates estimates before an episode ends. Q-learning is an off-policy TD method that learns the greedy optimal action value function.
</TLDR>

## Core idea

TD learning uses a bootstrapped target.

For value prediction:

$$
V(s_t)
\leftarrow
V(s_t)+\alpha
\left[
r_t+\gamma V(s_{t+1})-V(s_t)
\right].
$$

The term in brackets is the TD error:

$$
\delta_t
=
r_t+\gamma V(s_{t+1})-V(s_t).
$$

## Q-learning

Q-learning estimates the optimal action value function.

Its update is:

$$
Q(s_t,a_t)
\leftarrow
Q(s_t,a_t)+\alpha
\left[
r_t+\gamma \max_{a'}Q(s_{t+1},a')-Q(s_t,a_t)
\right].
$$

The behavior policy can explore.

The update target uses the greedy action.

This makes Q-learning off-policy.

See <a href="/learn/reinforcement-learning/on-policy-vs-off-policy">On-Policy vs Off-Policy</a>.

## Why bootstrapping helps

Monte Carlo methods wait for full returns.

TD methods update from one step.

TD targets have bias when values are imperfect.

They often have lower variance than full returns.

See <a href="/learn/reinforcement-learning/monte-carlo-vs-td">Monte Carlo vs TD</a>.

## Code example

```python
import numpy as np

q = np.zeros((n_states, n_actions))
alpha = 0.1
gamma = 0.99

def q_update(s, a, r, s_next):
    target = r + gamma * np.max(q[s_next])
    q[s, a] += alpha * (target - q[s, a])
```

## Common mistakes

Do not call Q-learning on-policy.

Do not forget exploration during data collection.

Do not use a large step size with unstable function approximation.
