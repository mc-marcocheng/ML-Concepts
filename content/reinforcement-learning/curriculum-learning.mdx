<TLDR>
Curriculum learning changes the training task distribution over time. A good curriculum gives useful learning signals before the full task becomes feasible.
</TLDR>

## Core idea

A curriculum orders tasks or examples.

In reinforcement learning, the agent may start with easier environments.

Then training moves toward harder environments.

This can help when rewards are sparse or exploration is hard.

## Curriculum variables

A curriculum can change many parts of a task.

It can change start states.

It can change goal distance.

It can change opponent strength.

It can change environment randomness.

It can change reward sparsity.

## Automatic curricula

A hand-designed curriculum can work.

Automatic curricula choose tasks based on progress.

One common idea samples tasks where the agent improves fastest.

Another idea samples tasks near the agent's success boundary.

## Risks

A curriculum can overfit the agent to easy tasks.

It can create a gap between training and final evaluation.

It can hide weaknesses if hard cases appear too late.

Domain randomization can help reduce this gap.

## Link to exploration

Curricula help exploration by making reward easier to find early.

They also help credit assignment by shortening the path to success.

See <a href="/learn/reinforcement-learning/credit-assignment-problem">Credit Assignment Problem</a>.

## Common mistakes

Do not keep the curriculum too easy.

Do not change the final objective by accident.

Do not evaluate only on curriculum tasks.
