<TLDR>
The span of vectors is the set of all their linear combinations. Rank counts the number of independent directions in that span.
</TLDR>

## Core idea

The span of vectors $v_1,\dots,v_k$ is:

$$
\operatorname{span}(v_1,\dots,v_k)
=
\left\{\sum_{i=1}^{k} c_i v_i : c_i \in \mathbb{R}\right\}.
$$

The rank of a matrix is the dimension of its column span.

This is also called the dimension of the image.

See <a href="/learn/linear-algebra/null-space-image-space">Null Space and Image Space</a>.

## Column rank and row rank

The column rank equals the row rank.

Thus, people usually say "the rank" of a matrix.

Rank tells how many independent directions the linear map preserves.

## Rank-nullity

For $A \in \mathbb{R}^{m \times n}$:

$$
\operatorname{rank}(A) + \operatorname{nullity}(A) = n.
$$

The input dimension splits into directions that affect the output and directions that map to zero.

<Proof title="Rank-nullity intuition">
Row reduction identifies pivot variables and free variables.

Each pivot variable gives one independent column direction.

Each free variable gives one independent null-space direction.

There are $n$ input coordinates in total.

Thus, the number of pivot variables plus the number of free variables is $n$.

This gives:

$$
\operatorname{rank}(A)+\operatorname{nullity}(A)=n.
$$
</Proof>

## Low rank

A low-rank matrix has fewer effective directions than its shape suggests.

Low-rank structure appears in compression, embeddings, and matrix factorization.

## Code example

```python
import numpy as np

A = np.array([[1.0, 2.0, 3.0],
              [2.0, 4.0, 6.0]])

rank = np.linalg.matrix_rank(A)
print(rank)
```

## Common mistakes

Do not confuse the shape of a matrix with its rank.

Do not assume columns span all of $\mathbb{R}^m$.

Do not forget that rank cannot exceed $\min(m,n)$.
