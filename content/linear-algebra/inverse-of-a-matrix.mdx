<TLDR>
An inverse matrix reverses a square linear map. It exists exactly when the matrix has full rank and nonzero determinant.
</TLDR>

## Core idea

A square matrix $A$ is invertible if there is a matrix $A^{-1}$ such that:

$$
A^{-1}A=I
$$

and

$$
AA^{-1}=I.
$$

The inverse reverses the action of $A$.

## Equivalent conditions

For an $n \times n$ matrix $A$, these statements are equivalent.

| Statement | Meaning |
|---|---|
| $A^{-1}$ exists | The map can be reversed |
| $\det(A)\neq 0$ | Volume does not collapse |
| $\operatorname{rank}(A)=n$ | Columns span all output directions |
| $Ax=0$ has only $x=0$ | No nonzero input maps to zero |

See <a href="/learn/linear-algebra/singular-matrices">Singular Matrices</a>.

## Solving systems

To solve:

$$
Ax=b,
$$

write:

$$
x=A^{-1}b.
$$

In numerical code, use a linear solver instead of forming $A^{-1}$.

This is usually faster and more stable.

## Two by two inverse

For:

$$
A=
\begin{bmatrix}
a & b \\
c & d
\end{bmatrix},
$$

if $ad-bc \neq 0$:

$$
A^{-1}
=
\frac{1}{ad-bc}
\begin{bmatrix}
d & -b \\
-c & a
\end{bmatrix}.
$$

## Why nonzero null space blocks an inverse

<Proof title="Nonzero null vector prevents an inverse">
Assume $Ax=0$ for some $x \neq 0$.

If $A^{-1}$ existed, multiply both sides by $A^{-1}$:

$$
A^{-1}Ax=A^{-1}0.
$$

This gives:

$$
Ix=0.
$$

Thus:

$$
x=0.
$$

This contradicts $x \neq 0$.

Therefore, $A$ cannot have an inverse.
</Proof>

## Code example

```python
import numpy as np

A = np.array([[2.0, 1.0],
              [3.0, 4.0]])
b = np.array([1.0, 2.0])

x = np.linalg.solve(A, b)
print(x)
```

## Common mistakes

Do not invert non-square matrices.

Do not compute an inverse only to solve a system.

Do not treat a near-singular matrix as numerically safe.
