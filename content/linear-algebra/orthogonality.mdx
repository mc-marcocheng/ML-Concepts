<TLDR>
Two vectors are orthogonal when their dot product is zero. Orthogonal bases simplify projections, norms, and least-squares problems.
</TLDR>

## Core idea

Vectors $a$ and $b$ are orthogonal if:

$$
a^\top b = 0.
$$

For nonzero vectors, this means the angle between them is $90^\circ$.

Orthogonality uses the <a href="/learn/linear-algebra/dot-product">Dot Product</a>.

## Orthogonal sets

A set of nonzero vectors is orthogonal if each pair has dot product zero.

It is orthonormal if each vector also has norm one.

For an orthonormal matrix $Q$:

$$
Q^\top Q = I.
$$

If $Q$ is square, then $Q^{-1}=Q^\top$.

See <a href="/learn/linear-algebra/inverse-of-a-matrix">Inverse of a Matrix</a>.

## Projection and residuals

Projection splits a vector into two parts.

$$
a
=
\operatorname{proj}_b(a)
+
r
$$

The residual $r$ is orthogonal to $b$.

This idea is central to least squares and data projection.

## Norm preservation

Orthogonal matrices preserve lengths.

<Proof title="Orthogonal matrices preserve norms">
Let $Q^\top Q=I$.

For any vector $x$:

$$
\|Qx\|^2
=
(Qx)^\top(Qx).
$$

Move the transpose inside:

$$
(Qx)^\top(Qx)
=
x^\top Q^\top Q x.
$$

Use $Q^\top Q=I$:

$$
x^\top Q^\top Q x
=
x^\top I x
=
x^\top x
=
\|x\|^2.
$$

Thus, $\|Qx\|=\|x\|$.
</Proof>

## Code example

```python
import numpy as np

a = np.array([1.0, 1.0])
b = np.array([1.0, -1.0])

is_orthogonal = abs(a @ b) < 1e-12
print(is_orthogonal)
```

## Common mistakes

Do not assume independent vectors are orthogonal.

Do not assume orthogonal means zero vector.

Do not ignore floating point tolerance in code.
