<TLDR>
A symmetric matrix is positive semi-definite when $x^\top A x$ is never negative. Its eigenvalues are all nonnegative.
</TLDR>

## Core idea

A symmetric matrix $A$ is positive semi-definite, or PSD, if:

$$
x^\top A x \ge 0
$$

for every vector $x$.

The value $x^\top A x$ is a quadratic form.

PSD matrices appear in covariance matrices, kernels, and Hessians.

See <a href="/learn/linear-algebra/hessian">Hessian</a>.

## Eigenvalue test

For a symmetric matrix, $A$ is PSD if and only if all eigenvalues are nonnegative.

It is positive definite if all eigenvalues are positive.

Positive definite matrices have strictly positive quadratic form for every nonzero $x$.

## Gram matrices

If $A=B^\top B$, then $A$ is PSD.

<Proof title="Gram matrices are PSD">
Let $A=B^\top B$.

For any vector $x$:

$$
x^\top A x
=
x^\top B^\top B x.
$$

Regroup the terms:

$$
x^\top B^\top Bx
=
(Bx)^\top(Bx).
$$

This is a dot product of $Bx$ with itself.

Thus:

$$
(Bx)^\top(Bx)=\|Bx\|^2 \ge 0.
$$

Therefore, $A$ is PSD.
</Proof>

## Optimization meaning

For a twice differentiable function, a PSD Hessian means nonnegative curvature.

For convex functions, the Hessian is PSD everywhere where it exists.

PSD matrices also define valid covariance matrices.

## Code example

```python
import numpy as np

A = np.array([[2.0, 1.0],
              [1.0, 2.0]])

eigvals = np.linalg.eigvalsh(A)
is_psd = np.all(eigvals >= -1e-12)

print(is_psd)
```

## Common mistakes

Do not apply the eigenvalue PSD test to a non-symmetric matrix without care.

Do not confuse PSD with all entries being nonnegative.

Do not confuse positive definite with positive semi-definite.
