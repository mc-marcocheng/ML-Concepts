<TLDR>
The null space contains inputs that a matrix sends to zero. The image space contains all outputs the matrix can reach.
</TLDR>

## Core idea

For a matrix $A \in \mathbb{R}^{m \times n}$, the null space is:

$$
\mathcal{N}(A)
=
\{x \in \mathbb{R}^n : Ax=0\}.
$$

The image space is:

$$
\operatorname{Im}(A)
=
\{Ax : x \in \mathbb{R}^n\}.
$$

The image space is the column span of $A$.

See <a href="/learn/linear-algebra/rank-span">Rank and Span</a>.

## Meaning

The null space contains directions that disappear.

The image space contains outputs the map can produce.

If $b$ is not in the image space, then $Ax=b$ has no solution.

If the null space has a nonzero vector, then solutions are not unique when they exist.

## Rank-nullity

For $A \in \mathbb{R}^{m \times n}$:

$$
\dim \mathcal{N}(A) + \dim \operatorname{Im}(A) = n.
$$

The first term is nullity.

The second term is rank.

## Orthogonality link

The null space of $A$ is orthogonal to the row space of $A$.

If $Ax=0$, then every row of $A$ has dot product zero with $x$.

See <a href="/learn/linear-algebra/orthogonality">Orthogonality</a>.

<Proof title="Null space is orthogonal to row space">
Let the rows of $A$ be $r_1^\top,\dots,r_m^\top$.

If $x \in \mathcal{N}(A)$, then $Ax=0$.

This means each output coordinate is zero.

Thus:

$$
r_i^\top x=0
$$

for every row $r_i$.

So $x$ is orthogonal to every row.

Therefore, $x$ is orthogonal to the row space.
</Proof>

## Code example

```python
import numpy as np

A = np.array([[1.0, 2.0],
              [2.0, 4.0]])

u, s, vh = np.linalg.svd(A)
null_vector = vh[-1]

print(null_vector)
```

## Common mistakes

Do not put output vectors in the null space.

Do not put input vectors in the image space.

Do not forget that nullity uses the input dimension.
