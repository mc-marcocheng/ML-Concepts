<TLDR>
LoRA freezes a base weight matrix and learns a low-rank update. It can reduce trainable parameters while keeping the original model usable.
</TLDR>

## Core idea

LoRA means low-rank adaptation.

For a frozen weight matrix $W$, LoRA learns:

$$
W' = W + \Delta W.
$$

The update has low rank:

$$
\Delta W = \frac{\alpha}{r}BA.
$$

Here $r$ is the rank.

If $W \in \mathbb{R}^{d_{\text{out}}\times d_{\text{in}}}$, then:

$$
A \in \mathbb{R}^{r \times d_{\text{in}}}
$$

and:

$$
B \in \mathbb{R}^{d_{\text{out}} \times r}.
$$

LoRA usually trains $A$ and $B$ only.

The base weight $W$ stays frozen.

## Why low rank helps

A full update to $W$ has $d_{\text{out}}d_{\text{in}}$ parameters.

A LoRA update has:

$$
r(d_{\text{in}}+d_{\text{out}})
$$

parameters.

This can be much smaller when $r$ is small.

Use <a href="/learn/linear-algebra/rank-span">rank and span</a> for the linear algebra.

## Where LoRA is applied

LoRA often modifies attention projections.

Common targets are:

- query projection
- key projection
- value projection
- output projection
- feed-forward projection

The best target depends on the task and memory budget.

## Merge and unmerge

After training, you can merge the update into the base weight:

$$
W_{\text{merged}} = W + \frac{\alpha}{r}BA.
$$

This removes extra LoRA operations at inference time.

You can also keep LoRA separate and swap adapters.

## Code example

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class LoRALinear(nn.Module):
    def __init__(self, in_features, out_features, rank=8, alpha=16):
        super().__init__()
        self.weight = nn.Parameter(torch.empty(out_features, in_features))
        self.weight.requires_grad_(False)

        self.A = nn.Parameter(torch.randn(rank, in_features) * 0.01)
        self.B = nn.Parameter(torch.zeros(out_features, rank))
        self.scale = alpha / rank

    def forward(self, x):
        delta = self.scale * (self.B @ self.A)
        return F.linear(x, self.weight + delta)
```

## Common mistakes

Do not train the frozen base weight by accident.

Do not assume a larger rank always helps.

Do not forget to scale the low-rank update.

Do not merge adapters twice.
